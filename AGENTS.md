# Инструкции для ИИ-агентов (AI Agents Instructions)

## Терминал (Terminal)
- Параметр `lineHeight` в настройках xterm.js (файл `src/components/Terminal.tsx`) **всегда** должен быть равен `1`. Запрещено изменять это значение на `1.1`, `1.2` или любое другое, даже в целях улучшения визуального стиля, если об этом явно не попросил пользователь в текущей сессии.
- При инициализации терминала важно соблюдать последовательность вызовов (pipeline), чтобы `fitAddon.fit()` выполнялся до установки SSH-соединения.

## Стили и Шрифты (Styles and Fonts)
- При указании путей к шрифтам в CSS файлах (через `@font-face`) **запрещено** использовать префикс `./`. Пути должны начинаться сразу с папки (например, `/fonts/...`), чтобы обеспечить корректную загрузку ассетов в продакшн-сборке Electron.
- ./icons/icon48.png в TitleBar должен быть в таком стиле
- ./icons/icon256.png в SettingsView должен быть в таком стиле

## Код и Типизация (Code and Typing)
- При написании кода следует избегать использования `any` и придерживаться строгой типизации (strict mode).

## Локализация (Localization)
- Общение с пользователем в чате ведётся на русском языке. В программном коде проекта (UI, сообщения, кнопки, тексты интерфейса) должны поддерживаться два языка: русский и английский.
- PR и описания коммитов также должны составляться на **русском языке**.

## Версионирование (Versioning)
- Если пользователь явно не указал, до какой версии обновлять, повышай версию только на `+0.0.1` за одну сессию. Пример: `1.8.1 → 1.8.2`.
