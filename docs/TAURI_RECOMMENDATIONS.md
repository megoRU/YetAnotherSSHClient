# Рекомендации по оптимизации и переходу на Tauri

## Текущие оптимизации (уже внедрены)

1.  **Оптимизация Electron**:
    - Отключены ненужные подсистемы Chromium (Speech API, Print Preview, HTTP Cache).
    - Оптимизирована работа с GPU и памятью через флаги запуска.
2.  **Производительность Терминала**:
    - Внедрен потоковый `TextDecoder`, что исключает ошибки при разрыве многобайтовых UTF-8 символов.
    - Оптимизирована логика подсветки (Regex вынесены из цикла рендеринга).
    - Настроены параметры `xterm.js` для мгновенной прокрутки и минимальной нагрузки на CPU при расчете контрастности.

## Почему стоит рассмотреть переход на Tauri?

Если основной целью является избавление от "мусора" Chromium и максимальная легкость приложения, **Tauri** — лучший выбор.

### Сравнение Electron и Tauri

| Характеристика | Electron (текущий) | Tauri (рекомендуемый) |
| :--- | :--- | :--- |
| **Размер установщика** | ~80-100 МБ | **~5-10 МБ** |
| **Потребление RAM** | Высокое (~150MB+ в простое) | **Низкое (~30-50MB)** |
| **Движок рендеринга** | Встроенный Chromium | Системный WebView (WebView2, WebKit) |
| **Безопасность** | Node.js в главном процессе | **Rust** (безопасность памяти) |
| **Сложность перехода** | — | Средняя (нужно переписать Main процесс на Rust) |

### План перехода (если решите переходить):

1.  **Frontend**: Практически не изменится. React + xterm.js продолжат работать так же, так как Tauri поддерживает стандартные веб-технологии.
2.  **Backend (Main процесс)**:
    - Логику SSH (библиотека `ssh2`) нужно будет заменить на нативную Rust-библиотеку (например, `russh` или `ssh2-rs`). Это даст огромный прирост производительности TTY.
    - IPC-обработчики (файловая система, конфиги) переписываются на Rust.
3.  **Безопасность**: Tauri позволит жестко ограничить доступ фронтенда к системным API (директории, сеть) через настройки `capabilities`.

**Вердикт**: Если приложение должно оставаться SSH-клиентом "на каждый день", который не ест ресурсы, переход на Tauri оправдан на 100%. Если важна скорость разработки и поддержка старых систем — Electron пока выигрывает.
