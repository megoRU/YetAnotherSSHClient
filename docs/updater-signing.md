# Подпись автообновлений Tauri

Для проверки обновлений Tauri использует пару minisign-ключей:

- **Публичный ключ** находится в `src-tauri/tauri.conf.json` (`plugins.updater.pubkey`). Он включается в приложение и нужен ему для проверки подписи.
- **Приватный ключ** подписывает собранные пакеты. Он создан локально в `.tauri/updater.key`, зашифрован паролем и исключён из Git через `.gitignore`.
- Пароль приватного ключа сохранён в `.tauri/updater-password.txt`; этот файл также исключён из Git.

Ключ сгенерирован командой `npx tauri signer generate`. Пароль — случайное 256-битное значение. Не отправляйте приватный ключ или пароль в чат, коммиты, issues или логи CI.

## Подключение GitHub Actions

В настройках репозитория откройте **Settings → Secrets and variables → Actions** и добавьте:

| Имя                                  | Значение                                                                 |
|--------------------------------------|--------------------------------------------------------------------------|
| `TAURI_SIGNING_PRIVATE_KEY`          | Полное содержимое `.tauri/updater.key`                                   |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | Содержимое `.tauri/updater-password.txt`                                 |
| `TAURI_UPDATER_PUBLIC_KEY`           | Публичный ключ из `plugins.updater.pubkey` в `src-tauri/tauri.conf.json` |

В **Actions → Variables** задайте `TAURI_UPDATER_ENABLED` в значение `true`. Workflow проверяет наличие всех трёх секретов, включает создание подписанных updater-артефактов и подставляет публичный ключ в конфигурацию сборки.

После проверки успешной CI-сборки сохраните резервную копию приватного ключа в менеджере секретов с ограниченным доступом. Парольный файл рядом с ключом удобен только для первоначальной настройки и не защищает ключ при одновременной утечке обоих файлов; после сохранения пароля в GitHub Secrets удалите `.tauri/updater-password.txt` с этого компьютера. Не теряйте резервную копию: уже установленные приложения будут принимать обновления только с подписью соответствующего приватного ключа.

Проверить, что локальные файлы игнорируются Git:

```powershell
git check-ignore .tauri/updater.key .tauri/updater.key.pub .tauri/updater-password.txt
```
