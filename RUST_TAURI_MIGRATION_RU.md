# Почему YASSH Client переходит на Rust + Tauri 2

YASSH Client переходит с Electron на **Rust + Tauri 2**, чтобы сделать приложение быстрее, легче и производительнее.

## Плюсы

- ⚡ **Быстрый запуск** — приложение запускается быстрее.
- 🧠 **Меньше RAM** — Tauri не поставляет собственный Chromium, как Electron.
- 🚀 **Высокая производительность** — Rust хорошо подходит для SSH, SFTP, файловых и сетевых операций.
- 📁 **Более быстрый SFTP** — Rust позволяет эффективнее обрабатывать загрузку, скачивание и работу с файлами.
- 📦 **Меньший размер приложения**.
- 🔒 **Безопасность и надёжность Rust**.
- 🖥️ **Нативная интеграция** с Windows, macOS и Linux.
- 🔄 **Автообновления** через Tauri Updater.

## Минусы

### Linux

Linux пока остаётся самой сложной платформой.

Возможны проблемы с:

- Pacman;
- автоматическими обновлениями;
- различными форматами пакетов (`deb`, `rpm`, AppImage и другие).

Для Linux может потребоваться отдельная логика обновлений в зависимости от способа установки.

### Rust

В проекте появляется новый язык — Rust. Это увеличивает сложность разработки и поддержки нативной части приложения.

## Обновления

- **Windows** — принципиально ничего нового, текущая схема остаётся привычной.
- **macOS** — автообновления будут работать через Tauri Updater.
- **Linux** — автообновление зависит от формата установки и может потребовать дополнительной работы.

## Итог

Главная цель перехода — получить **более быстрый запуск, меньшее потребление памяти и высокую производительность**, особенно в SSH/SFTP.

React остаётся интерфейсом, а Rust + Tauri 2 берут на себя нативную и производительную часть приложения.

## Как сделать миграцию

Дождитесь, когда в **Latest** на GitHub появится версия **4.\*.\*** или выше.

1. Удалите с компьютера предыдущую версию YASSH Client.
2. Желательно удалить из `%AppData%` всё, что связано с `YetAnotherSSHClient`.
3. Установите последнюю версию из GitHub.

**Ваш конфиг при этом останется** и подходит для новой версии.

Единственное исключение — при первом запуске может измениться **позиционирование и размер окна**. После этого настройки окна будут сохранены как обычно.
